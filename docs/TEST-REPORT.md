# Focus — 테스트 결과 (2026-09-05, 첫 릴리즈)

버전: `2026.09.05-freshstart1`. git 히스토리를 정리하고 첫 배포처럼 보이도록 리셋한 릴리즈입니다.

## 통과 항목 (`npm test`, 22/22 통과)

- 세 가지 저장 세션 모드(집중/짧은 휴식/긴 휴식) 모두 완전한 journal 기록을 생성함
- journal 날짜는 저장된 `endedAt`의 로컬 날짜 기준으로 결정됨
- content-off 세션은 제목·작업 내용을 노출하지 않음 (redaction 확인)
- redaction이 Focus 타이밍 메타데이터는 보존하고 비공개 내용만 제거함
- 삭제는 기존 레코드를 지우지 않고 더 최신 tombstone을 추가하는 방식으로 동작 (비밀 아님 필드는 유지)
- `createTimer`/`restoreTimer`가 설정값 기준으로 정확히 초기화·복원됨 (idle 복귀, 벽시계 기준 잔여시간 재계산 포함)
- 모드 전환 로직(`nextModeAfter`)이 focus/짧은 휴식 순환과 설정된 주기의 긴 휴식 삽입을 올바르게 처리
- `adjustedMinutes`가 1~180 범위로 항상 clamp됨
- `MODES`, `FONT_SCALES` 구조가 설정 화면·CSS 변수 의존성과 어긋나지 않음
- 통계 헬퍼(연속일수, 오늘 합계, 7일 버킷)가 기존과 동일하게 동작
- 백업 가져오기·단일 삭제·전체 삭제가 로컬 스토리지 호출과 올바르게 연결됨
- journal opt-in은 기본 꺼짐 상태의 별도 키를 쓰고, shared/v2를 동적 import로만 불러옴
- shared sync v1은 동기화 작업이 실제로 요청될 때만 상대 경로 import로 로드됨 (shared/v1은 frozen 규칙 준수)
- 동기화·journal 모두 GitHub Pages 호스트명에서 저장소 소유자를 올바르게 추출함
- 빌드 도구 불필요 (번들러 설정·JSX·npm 의존성 없음) 확인
- 서비스 워커 캐시 버전과 화면에 표시되는 빌드 버전이 일치함
- 미니멀 모드 설정이 타이머 화면·설정 화면에 올바르게 연결됨
- 기존 빌드와 동일한 localStorage/IndexedDB 키를 그대로 사용함
- 백업 파일 형식(`{app: "Focus", version: 1, settings, sessions}`)이 변경되지 않음

## Fresh-start 데이터 리셋 동작

이번 릴리즈에서 "첫 릴리즈"로 보이도록 데이터 리셋 로직이 추가되었습니다. 기존 사용자의 IndexedDB 세션 기록·localStorage 설정을 삭제하는 것이 아니라, 표시상 버전·히스토리만 첫 배포처럼 정리한 것이며, 백업 파일 형식과 저장 키는 위 테스트대로 기존과 동일하게 유지됩니다.
