# Focus 사용 안내

## 시작하기

1. Safari에서 Focus 주소를 엽니다.
2. 공유(Share) → 홈 화면에 추가(Add to Home Screen)로 설치합니다.

## 타이머 사용

- 상단 세그먼트로 **집중 / 짧은 휴식 / 긴 휴식** 모드를 고릅니다.
- 원 옆의 −/＋ 버튼으로 이번 회 시간을 1분 단위로 조절할 수 있습니다 (설정의 기본 시간과 별개로, 그 순간만 조절).
- 과목·작업 이름을 입력하면 기록에 함께 저장됩니다.
- **시작 → 일시정지/계속 → 종료** 순서로 진행하며, 종료 시점까지의 실제 사용 시간이 기록됩니다.
- 긴 휴식 주기(기본 4회)에 도달하면 자동으로 긴 휴식 모드로 전환됩니다.

## 기록과 통계

- 오늘의 집중 시간, 완료 세션 수, 연속 기록(streak)을 볼 수 있습니다.
- 최근 7일 막대 차트와 날짜별 상세 내역(펼치기)을 제공합니다.
- 최근 세션 목록에서 개별 기록을 삭제할 수 있습니다.

## 글자 크기 조절

설정(Settings) → **글자 크기**에서 1~6단계 중 −/＋ 버튼으로 고를 수 있습니다.

- **4단계가 지금까지 써 오신 기본 크기**입니다.
- 1~3단계는 더 작게, 5~6단계는 더 크게 보입니다.
- 시간 입력창은 어떤 단계에서도 같은 크기를 유지해 Safari가 화면을 자동으로 확대하지 않습니다.
- 기본이 아닐 때만 **기본 크기로 되돌리기** 버튼이 나타납니다.
- 선택한 크기는 기기에 저장되어 다음에 열어도 유지됩니다.

## 알림 설정

- **완료 알림음 / 진동 / 화면 알림**을 각각 켜고 끌 수 있습니다.
- 화면 알림을 켜면 iOS가 알림 권한을 요청합니다. iOS 설정 → 알림에서 Focus가 꺼져 있으면 화면에 안내가 표시됩니다.
- **자동으로 다음 세션 시작**을 켜면 세션이 끝나자마자 다음 모드가 바로 시작됩니다.

## 백업과 복원

- 설정 → **iCloud 백업 저장**: 공유 시트가 뜨면 **파일에 저장**을 선택해 iCloud Drive에 보관하세요.
- 설정 → **백업 가져오기**: JSON 백업 파일을 불러와 기존 기록과 안전하게 합칩니다(같은 id는 최신 내용으로 갱신).
- 오래 백업하지 않으면 백업 버튼 아래 안내에 "백업 필요" 표시가 뜹니다.

## 기록 삭제

설정 화면 맨 아래 **모든 기록 삭제**는 되돌릴 수 없습니다. 확인 창이 한 번 더 뜨니, 필요하면 삭제 전에 백업부터 저장하세요.

## 동기화 켜기 (Sync)

동기화는 처음에 꺼져 있습니다. 켜지 않아도 앱은 그대로 다 됩니다.
켜면 기록이 내 비공개 저장소에도 함께 저장되어, 다른 기기와 Atlas·Trace에서 볼 수 있습니다.

1. 설정(Settings)을 엽니다.
2. **동기화(Sync)** 항목의 **GitHub token** 칸에 토큰을 붙여 넣고 **Save token**을 누릅니다.
   - `webapp-data` 저장소에 대한 Contents: Read and write 권한이 필요합니다.
   - Tide·Trace·Atlas와 **같은 토큰**을 씁니다. 한 곳에서 저장하면 나머지도 함께 바뀝니다.
3. **Sync this device** 스위치를 켭니다.
4. **Name for this device**에 이 기기를 알아볼 이름을 적습니다. **스위치를 켜기 전에 적으세요.**
   - 이 이름의 영문·숫자가 저장소 파일 이름에 들어갑니다. 예: `iPhone Home Screen` → `iphone-home-screen-3f2a1b9c`
   - 한글로만 적으면 파일 이름은 `context-3f2a1b9c` 가 됩니다. 화면에 보이는 이름은 한글 그대로 남습니다.
   - **파일 이름은 처음 켤 때 정해지고 이후 바뀌지 않습니다.** 나중에 이름을 고치면 화면 표시만 바뀝니다.
   - 같은 iPhone이라도 Safari와 홈 화면에 추가한 앱은 **서로 다른 기기로 셉니다.**
     둘 다 쓰신다면 각각 켜고 이름을 다르게 주세요.
   - 설정의 **File name** 줄에서 이 기기의 파일 이름을 확인할 수 있습니다.
5. **Last synced**에 시간이 뜨고 **Last error**가 `No errors`이면 준비가 끝났습니다.

### 언제 올라가나요

집중 세션을 완료하면 그때 자동으로 올라갑니다. 화면이 멈추지 않고, 실패해도 기록은 기기에 남습니다.
보내지 못한 것은 **Waiting to send**에 개수로 보이고, 다음에 성공할 때 함께 올라갑니다.
직접 올리고 싶으면 **Sync now**를 누르세요.

올라가는 것은 **집중 세션**입니다. 휴식은 올라가지 않고, 과목·작업 이름도 넣지 않습니다.

중간에 끝낸 집중도 올라갑니다. focus 앱이 그 시간을 실제 집중 시간으로 세기 때문입니다.
기록에는 이렇게 구분되어 남습니다.

| 상황 | Atlas·Trace 에 보이는 문구 |
|---|---|
| 끝까지 완주 | `Finished a 25-min focus session` |
| 중간에 종료 | `Focused for 12 min` |

**1분 미만은 올라가지 않습니다.** 실수로 눌렀다 끈 것을 기록으로 남기지 않기 위해서입니다.

### GitHub에 백업하기 (Back up to GitHub)

설정 → 데이터(Data) → **Back up to GitHub**을 누르면 그날 날짜로 백업이 저장됩니다.
같은 날 다시 누르면 그날 파일을 덮어쓰고, **최근 12개**만 남습니다.

기기 파일로 내보내는 **Save a backup file**은 그대로 있습니다. 둘 다 쓰셔도 됩니다.

### 잘 안 될 때

설정 → 동기화(Sync) → **Last error**를 확인하세요.

- `Token may be expired or lacks permission` — 토큰이 만료됐거나 권한이 부족합니다. 새 토큰을 저장하세요.
- `Network unavailable. Changes are queued.` — 연결이 없습니다. 기록은 기기에 남아 있고 나중에 다시 보냅니다.
- `Another device wrote first. Queued to send again.` — 다른 기기가 먼저 썼습니다. 다시 시도하면 합쳐집니다.
- `The file is too large to sync.` — 파일이 너무 큽니다. 기기 파일로 내보내세요.
